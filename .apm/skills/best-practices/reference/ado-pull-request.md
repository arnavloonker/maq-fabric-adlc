# ADO pull request

MAQ-authored guidance for a pull request opened from this package's workflow. Apply these points; do not stop at the link title.

- One pull request covers one approved tracer bullet, and it links to the story without closing the work item.
- The description states what changed, which seam was checked, and what remains unverified.
- Do not enable autocomplete, merge, or bypass branch policy. Closure stays with a person.
- Do not include secrets, connection strings, tokens, or raw sensitive rows.
- A reviewer checks the seam evidence against the story, not the diff size alone.
